# Research log

## 2026-07-27 — Evolutionary coding evaluation protocol

### AlphaEvolve: A coding agent for scientific and algorithmic discovery

- Authors: Alexander Novikov et al.
- Published: 2025-06-16
- Link: https://arxiv.org/abs/2506.13131
- Relevance: Supports evaluator-driven evolutionary code search across heterogeneous
  scientific and systems tasks. Motivated retaining a multi-task suite instead of
  judging the framework on sort optimization alone.

### Mathematical discoveries from program search with large language models

- Authors: Bernardino Romera-Paredes et al.
- Published: 2023-12-14
- Link: https://doi.org/10.1038/s41586-023-06924-6
- Relevance: FunSearch demonstrates the value of executable evaluators plus evolutionary
  sampling. It motivates keeping an evaluator-first fast loop and a genuine random-search
  baseline.

### Is Your Code Generated by ChatGPT Really Correct? Rigorous Evaluation of Large
Language Models for Code Generation

- Authors: Jiawei Liu, Chunqiu Steven Xia, Yuyao Wang, Lingming Zhang
- Published: 2023-05-02
- Link: https://arxiv.org/abs/2305.01210
- Relevance: EvalPlus shows that insufficient tests can materially mis-rank systems.
  Motivated hidden immutable test mounts, integrity digests, fail-closed parsing, and
  explicit anti-peeking checks.

### LiveCodeBench: Holistic and Contamination Free Evaluation of Large Language Models
for Code

- Authors: Naman Jain et al.
- Published: 2024-03-12
- Link: https://arxiv.org/abs/2403.07974
- Relevance: Motivated separating public task descriptions from hidden evaluation inputs
  and recording evaluator/environment versions so results can be refreshed and replayed.

### Can Language Models Solve Olympiad Programming?

- Authors: Quan Shi, Michael Tang, Karthik Narasimhan, Shunyu Yao
- Published: 2024-04-16
- Link: https://arxiv.org/abs/2404.10952
- Relevance: Its diverse problems, high-quality tests, reference solutions, and inference
  baselines support using a heterogeneous 8–12 task protocol rather than a single domain.

### CodeEvolve: an open source evolutionary coding agent for algorithmic discovery and
optimization

- Authors: Henrique Assumpção, Diego Ferreira, Leandro Campos, Fabricio Murai
- Published: 2025-10-15; revised 2026-05-28
- Link: https://arxiv.org/abs/2510.14150
- Relevance: Its nine-problem matched comparison and component ablations directly
  motivated the 9-task × 5-seed matrix and full/random/single-agent/no-novelty/no-slow-loop
  variants used here.
