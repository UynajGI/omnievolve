# 里程碑与阶段门

| 里程碑 | 触发点 | 必须证据 | Go 条件 | No-Go 处理 |
|---|---|---|---|---|
| M0 Scope Freeze | 开发前 | scope、非目标、实体图、安全边界、默认平台 | P0 无歧义 | 不开始正式编码 |
| M1 Storage & Sandbox | S1+S2 | schema tests、CAS tests、安全攻击测试、Environment digest | 默认隔离生效，数据不半写 | 冻结 S3+，先修 P0 |
| M2 Reproducible Core | S3+S4 | EvaluationRun 重放、500 候选 soak、kill -9 fault injection | 无重复 committed run，可完整追溯 | 不进入 Agent/Memory |
| M3 Long-Horizon Search | S5–S7 | Agent E2E、outbox reconcile、memory attribution、novelty regression | 检索/记忆/多样性可测且无严重污染 | 降级或重做检索，不上完整 MCTS |
| M4 Health-Aware Loop | S8 | 指标边界测试、router replay、HealthPolicy 迟滞测试 | 指标稳定，可支持 L0 建议/调参 | 只展示，不自动应用 |
| M5 v0.2 Alpha | S9 | E2E、500 回归、audit report、安装矩阵、用户指南 | P0 全关，P1 有明确处置 | 延期发布或标记 Demo |

## Phase 1 验收清单

- [ ] 单任务执行 ≥500 个候选不丢已提交状态。
- [ ] kill -9 后不重复提交已完成 EvaluationRun。
- [ ] 租约过期任务可重新认领。
- [ ] 候选默认无法读取宿主 API Key、访问外网或越权挂载。
- [ ] 任一结果可还原至 Artifact/Evaluator/Environment/Seed。

## Phase 2 验收清单

- [ ] EmbeddingProfile 更换不覆盖旧索引。
- [ ] SQLite/zvec 中断后可 reconcile。
- [ ] NoveltyGate 不由单 cosine 阈值直接拒绝。
- [ ] 记忆的检索、引用、采用、结果均可追踪。
- [ ] 岛屿/融合血缘与 reference edge 可审计。

## Phase 3 验收清单

- [ ] 健康指标绑定 SearchPolicyVersion 和窗口。
- [ ] Director/Coder/Critic 奖励分开统计。
- [ ] Champion Policy 可导出、应用、回滚。
- [ ] L0 调参不修改任务评估语义。
- [ ] CLI audit 可追踪最佳候选完整 provenance。
