- 依赖、测试夹具、目标平台和配置已准备。
- 不存在未处理的 P0 设计分歧。

- [ ] 所有关键路径任务 Done；非关键任务若延期必须更新 scope 与风险。

## Sprint Review 重点

1. 是否真正满足设计边界，而非仅有演示路径。
2. 是否引入新的隐式全局状态、越权执行或双重真相源。
3. 是否可以故障恢复、重放和审计。
4. 是否需要砍 scope，而不是把风险推迟到发布前。
