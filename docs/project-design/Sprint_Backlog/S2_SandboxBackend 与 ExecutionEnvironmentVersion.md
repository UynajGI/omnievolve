# S2 Sprint Backlog：SandboxBackend 与 ExecutionEnvironmentVersion

> Phase：Phase 1  
> 推荐周期：6 个工作日  
> 阶段门：M1-B：Secure Execution Ready  
> 设计追溯：第二章安全执行、第三章 sandbox、第九章、ADR 4/9

## Sprint Goal

建立默认安全执行边界，使候选代码无法直接接触宿主机秘密、网络和非授权文件。

## 进入条件（Definition of Ready）

- 上游关键接口已冻结并有版本号。
- 所有 A 级任务明确 owner 和审查人。
- 依赖、测试夹具、目标平台和配置已准备。
- 不存在未处理的 P0 设计分歧。

## Sprint Review 重点

1. 是否真正满足设计边界，而非仅有演示路径。
2. 是否引入新的隐式全局状态、越权执行或双重真相源。
3. 是否可以故障恢复、重放和审计。
4. 是否需要砍 scope，而不是把风险推迟到发布前。
