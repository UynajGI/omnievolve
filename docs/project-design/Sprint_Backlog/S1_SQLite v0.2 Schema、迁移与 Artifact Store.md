## 进入条件（Definition of Ready）

- 上游关键接口已冻结并有版本号。
- 所有 A 级任务明确 owner 和审查人。
- 依赖、测试夹具、目标平台和配置已准备。
- 不存在未处理的 P0 设计分歧。

## Sprint Definition of Done

- [ ] 所有关键路径任务 Done；非关键任务若延期必须更新 scope 与风险。
- [ ] 新增公共接口有 contract tests 和文档。
- [ ] 数据/状态变更有迁移或向后兼容策略。
- [ ] P0/P1 缺陷已关闭或在阶段门由用户接受。
- [ ] 交付物可从干净环境复现。
- [ ] 更新 `03_WBS总表.md` 状态、`07_风险登记册.md` 和 `10_需求追溯矩阵.md`。

## Sprint Review 重点

1. 是否真正满足设计边界，而非仅有演示路径。
2. 是否引入新的隐式全局状态、越权执行或双重真相源。
3. 是否可以故障恢复、重放和审计。
4. 是否需要砍 scope，而不是把风险推迟到发布前。
