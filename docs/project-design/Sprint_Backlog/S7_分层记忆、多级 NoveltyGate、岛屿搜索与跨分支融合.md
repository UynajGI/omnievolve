# S7 Sprint Backlog：分层记忆、多级 NoveltyGate、岛屿搜索与跨分支融合

> Phase：Phase 2  
> 推荐周期：7 个工作日

## Sprint Goal

在不引入完整高风险 MCTS 的前提下，获得可解释的长程搜索、记忆归因和多样性保持。

## 进入条件（Definition of Ready）

- 上游关键接口已冻结并有版本号。
- 所有 A 级任务明确 owner 和审查人。
- 依赖、测试夹具、目标平台和配置已准备。
- 不存在未处理的 P0 设计分歧。

## Sprint Review 重点

1. 是否真正满足设计边界，而非仅有演示路径。
2. 是否引入新的隐式全局状态、越权执行或双重真相源。
3. 是否可以故障恢复、重放和审计。
4. 是否需要砍 scope，而不是把风险推迟到发布前。
