# 配置、版本与发布计划

## 1. 版本对象

必须独立版本化：

- SchemaVersion
- Artifact Manifest Version
- TaskEvaluatorVersion
- ExecutionEnvironmentVersion
- PromptVersion
- EmbeddingProfile
- SearchPolicyVersion
- ConfigSnapshot
- Package Version

## 2. 兼容策略

- 数据库只允许向前迁移，回滚通过备份或兼容视图，不做危险逆迁移。
- Artifact 以内容 hash 不变；Manifest 新字段必须向后兼容。
- Evaluator/Environment/Policy 为不可变版本，修改即创建新版本。
- EmbeddingProfile 更换创建新索引，不覆盖旧目录。
- CLI 输出 JSON 需维护 schema version。

## 3. 发布阶段

| 阶段 | 标识 | 条件 | 目标用户 |
|---|---|---|---|
| Dev Snapshot | 0.2.0.devN | 单 Sprint 内部集成 | 开发者 |
| Internal Alpha | 0.2.0a1 | M4 通过，S9 E2E 未完全关闭 | 内部测试 |
| Public Alpha | 0.2.0a2+ | M5 Go，文档/安装/审计可用 | 早期用户 |
| Beta | 0.2.0b1 | 多任务验证、API 收敛、兼容承诺 | 扩大测试 |
| Stable | 0.2.0 | 安全审计、迁移策略、真实长期运行 | 生产试用 |

## 4. 安装矩阵

- `omnievolve-core`：SQLite + Artifact + NumPy + trusted mode，仅开发/可信代码。
- `omnievolve-local`：core + zvec + local embedding + Docker，推荐。
- `omnievolve-full`：local + 多模型 + Hardened/remote adapters，后续。

## 5. Release Artifact

- schema migration scripts
- Docker image digest
- example evaluator/task
- sample config
- architecture/audit/security docs
- CHANGELOG、known issues、migration guide
