# OmniEvolve v0.2 阶段三任务拆解包

> 基线：`OmniEvolve_v0.2.md`（2026-07-19）

## 默认执行基线

- **发布目标**：OmniEvolve v0.2 Alpha。
- **推荐周期**：10 周；总工程工作量约 39–54 人日，不含 Phase 4。
- **关键策略**：先可信底座，后搜索能力，再健康自适应；不先写 Meta-Agent 或完整 MCTS。
- **默认 scope cut**：首版仅 Python 候选；默认 DockerBackend；轻量 Progressive MCGS；L0 元进化；不做无边界 Harness 自重写。
- **用户决策点**：里程碑 M0、M2、M3、M4、M5 需要确认优先级或砍 scope。

## 状态字段

`Not Started` → `Ready` → `In Progress` → `In Review` → `Blocked` / `Done` / `Dropped`

只有满足任务卡中的验收条件并提交证据链接后，才可标记 `Done`。
